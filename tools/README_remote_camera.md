## ขั้นตอนที่ 1: ฝั่งเพื่อน (เครื่อง Laptop `wissarut`)

1. ส่งโฟลเดอร์ `tools/` (หรืออย่างน้อย 2 ไฟล์: `start_friend_cam.bat` และ `friend_cam.py`) ให้เพื่อน
2. ให้เพื่อน **ดับเบิลคลิกที่ไฟล์ `start_friend_cam.bat`**
   - โปรแกรมจะตรวจสอบ Python และติดตั้ง `flask` กับ `opencv-python` ให้อัตโนมัติ
   - หาก Windows Defender Firewall เด้งเตือน ให้กด **"Allow access" (อนุญาต)**
3. หน้าต่าง Command Prompt ของเพื่อนจะแสดงข้อความ:
   ```text
   ================================================================
     🎥 CCTV Friend Camera Streamer กำลังทำงาน!
   ================================================================
     🌐 ตรวจพบ Tailscale IP: 100.88.228.119
     👉 URL ที่ต้องนำไปใส่ใน Dashboard ของเครื่อง PC:
        http://100.88.228.119:5001/video
   ----------------------------------------------------------------
     🖥️ ดูพรีวิวภาพได้ที่: http://localhost:5001
   ================================================================
   ```
4. เพื่อนสามารถเปิดดูภาพกล้องตัวเองได้ที่ `http://localhost:5001` เพื่อเช็คว่ากล้องติดปกติ

---

## ขั้นตอนที่ 2: ฝั่งคุณ (เครื่อง PC / Dashboard)

1. เปิดเบราว์เซอร์ไปที่ Dashboard: [http://localhost:5000](http://localhost:5000)
2. นำภาพเข้า Dashboard ได้ 2 วิธี:

### วิธีที่ A: ผ่านหน้า Settings (แนะนำ)
- ไปที่เมนู **Settings (ตั้งค่า)** แถบซ้ายมือ
- ในกล่อง **"กล้องระยะไกล · Remote Camera"**:
  - ช่อง **URL สตรีมของเพื่อน**: วาง `http://100.88.228.119:5001/video`
  - ช่อง **ชื่อกล้อง**: ตั้งชื่อ เช่น `กล้องโน้ตบุ๊กเพื่อน`
  - ช่อง **ใส่ในช่อง**: เลือก `Camera 1` หรือ `Camera 2`
  - กดปุ่ม **✔ ทดสอบการเชื่อมต่อ** (ระบบจะขึ้นแจ้งเตือนสีเขียวว่าเชื่อมต่อสำเร็จพร้อมขนาดภาพ)
  - กดปุ่ม **▶ เชื่อมต่อ**
- กลับไปที่หน้า **Dashboard** ภาพจากกล้องของเพื่อนจะขึ้นแสดงผลพร้อมระบบตรวจจับ YOLO ทันที!

### วิธีที่ B: ทางลัดหน้า Dashboard โดยตรง
- ที่การ์ด **Camera 1** หรือ **Camera 2** บนหน้า Dashboard
- คลิกที่ไอคอนเฟือง **⚙** มุมบนขวาของการ์ด
- วาง URL: `http://100.88.228.119:5001/video` แล้วกด OK
